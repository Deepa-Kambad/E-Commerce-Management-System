# E-Commerce Management System

## Project Overview
This project is a MySQL-based E-Commerce Management System designed to manage customers, products, inventory, shopping carts, orders, and payments.

## Technologies Used
- MySQL
- SQL
- MySQL Workbench

## Database Features
- Database and table creation
- Primary keys and foreign keys
- SQL Joins and Subqueries
- Views and Indexes
- Stored Procedures
- Triggers
- Transactions
- Order and Inventory Management
- Sales Reports and Business Analytics

## Database Tables
1. Customers
2. Categories
3. Products
4. Inventory
5. Cart
6. Cart Items
7. Orders
8. Order Items
9. Payments

## How to Run
1. Install MySQL Server and MySQL Workbench.
2. Download the `ecommerce_db.sql` file.
3. Open the file in MySQL Workbench.
4. Execute the SQL script.
5. Explore the database tables and queries.
